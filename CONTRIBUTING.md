# Contribuindo

Obrigado por contribuir com o La Vai La Vem Turismo.

## Fluxo recomendado

1. Abra uma issue descrevendo o problema ou a melhoria antes de mudanças
   grandes.
2. Crie uma branch curta e focada.
3. Faça a alteração sem incluir chaves, dados de clientes ou números privados.
4. Execute `pnpm run typecheck` e as verificações relevantes do README.
5. Abra um pull request explicando o que mudou, como validar e eventuais
   limitações.

## Diretrizes

- Preserve o atendimento em português brasileiro.
- Mantenha as chaves de provedores no servidor.
- Ao alterar o contrato de uma API, atualize a especificação e o código gerado.
- Ao alterar preços, horários ou políticas, atualize o catálogo e os prompts
  relacionados.
- Prefira componentes e funções pequenos, com nomes claros.
- Não adicione dependências sem necessidade.

## Pull requests

Um pull request deve incluir:

- contexto do problema;
- resumo da solução;
- passos para validação;
- screenshots ou gravação quando houver mudança visual;
- nota sobre alterações de configuração ou variáveis de ambiente.
